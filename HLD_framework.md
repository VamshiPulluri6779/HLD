System Design interview - 45min

1. Requirements(Functional and non-functional requirements) - 5min
2. Core entities(Identify important domain objects) - 2min
3. API Design(Define system interfaces and contracts) - 5min
4. High-level architecture(Components, storage and data flows) - 13min
5. Deep dives(Scaling, consistency, concurrency and failures) - 15min
6. Trade-offs and wrap-up(Validate design and discuss improvements) - 5min

-> For a 60-minute round, use the additional time primarily for deep dives, interviewer probes and failure scenarios
